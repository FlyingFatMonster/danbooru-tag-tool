  2.2  Danbooru 公开数据
────────────────────────────────────────────────────────────────────────────────

  文件：  lib\impl.js      Danbooru 隐含关系（tag_implications）+ 子类索引
          lib\tgroup.js    Danbooru 官方 tag_groups 分类表
          lib\library.js   标签词库（标签名、分类号、分级，源自 Danbooru 标签体系）

  来源：  Danbooru 公开站点与 API
          https://danbooru.donmai.us/
          API 端点：
            /tag_implications.json      隐含关系
            /tag_groups.json            官方分类分组
            /wiki_pages.json            标签 wiki 正文（含 [[Tag group:Xxx]] 标注）
            /tags.json                  标签列表、分类号、分级

  性质：  Danbooru 是公开的标签图库站点，其标签体系（tag vocabulary）是
          事实性数据集合，通过公开 API 可自由读取。

  处理说明：
    · 只取用标签名、分类号、分级、隐含关系、官方分组这些结构化字段
    · post_count（热度）虽可从 API 获取，但已被完全剔除，从未写入任何文件
    · 中文翻译为后续人工/AI 校对产物，不属于 Danbooru 原始数据

  ★ 声明：
    本工具与 Danbooru 官方无任何关联，未获其背书或授权。
    「Danbooru」为其各自权利人的商标，此处仅作来源说明之用。
    如需商用或大规模再分发，建议自行确认 Danbooru 的最新服务条款：
