# 标签查询工具 · 自动版

> 把中文口语描述翻译成 Danbooru 英文标签，并自动组装成可直接使用的正向 / 负向提示词。

**完全离线 · 零依赖 · 双击即用 · 不联网 · 不上传任何数据**

## 这是什么

一个纯前端、纯本地的 AI 绘图提示词(Tag)查询与组装工具。

用中文说你想画什么 ——「黑发红眼的少女穿白色比基尼站在沙滩上」——
工具会把它翻译成 `1girl, black_hair, red_eyes, white_bikini, beach, standing`
这样的 Danbooru 标签，并按最优顺序自动组装成提示词。

**它不调用任何 AI、不联网、不上传任何内容。** 所有匹配都在你本机的浏览器里完成。

## 特性

### 🎯 中文 → 标签

- **76,431 个中文映射键 / 81,561 条映射** —— 覆盖日常口语、NSFW 术语、书面描述
- **口语识别**：「自己玩」「扣」「揉下面」都能理解
- **错别字容错**：「裙紫」「内库」「屁服」「嘴吧」「眼晴」也能识别
- **同音字归一化**：内置 137 对同音字表
- **中英混合**：「69式」「T字裤」「2穴」「Q版插」这类词也能解析

### 🔍 英文标签查询

- 直接输入 `panties` / `long_hair` / `school_uniform`
- 拼错也能纠错：`pantys` → `panties`
- 单复数自动识别：`golds` → `gold`，`underwears` → `underwear`
- 大小写、连字符、下划线、全角字符全部归一化

### ⚡ 智能自动勾选

- 每个概念只勾选最精准的一个
- 互斥处理（红发 vs 黑发不会同时出现）
- 材质豁免（透明的比基尼 + `transparent` 都能保留）
- 噪音过滤（cosplay 专名、截断误配）

### 🔗 自动组装

- **覆盖率 75.2%**，一致性 **69.3%**
- 13,616 个下位词参与父子抑制（`1girl` 抑制 `girl`）
- 同义组只保留首选（`large_breasts` 抑制 `huge_breasts`）
- 按 15 个内容字段的最优顺序输出

### 👤 角色 / 作品 / 画师扩展库

- **角色 97,318 条**：初音未来、博丽灵梦、芙兰朵露·斯卡蕾特…
- **作品 17,152 条**：东方Project、蔚蓝档案、原神、赛马娘…
- **画师 31,568 条**：只收有中文名的
- 默认不加载，点按钮才载入（不占首屏内存）
- 括号名自动拆分：搜「阿尔托莉雅」能命中「阿尔托莉雅·潘德拉贡 (泳装Ruler) (Fate)」

### 🎨 20 个模型预设

自动填充对应的画质词和负向提示词。支持 SD1.5 / SDXL / Pony / Illustrious / NoobAI / Animagine 等。

### 📊 Token 预算与精简建议

- 实时显示 token 占用（区分核心区 / 扩写区）
- 超预算时给出精简建议，但**绝不自动删除任何词**
- 所有建议都要你自己确认

### 🗂 两种分类视图

- **15 字段**：画面质量 / 镜头构图 / 人数角色 / 穿着裸露 / ……
- **16 类**：身份规格 / 角色作品 / 外貌 / 发型发色 / ……
- 一键切换，勾选状态和输出顺序完全不变

### 方式一：直接用（推荐）


## 设计原则

这个工具有四条不可违背的红线：

### ① 不审核内容

工具不对任何标签做内容判断。你想画什么就搜什么。

### ② 不因映射不精确就删

宁可给你一个不够准的标签，也不轻易删掉映射关系。
只有「语义完全错误」的映射才会被清理，且每条都有正确替代。

### ③ 永远保留可达性

每个标签至少保留一个能搜到它的入口。

### ④ 绝不按热度排序

**`post_count`（Danbooru 热度）从未进入本工具的任何数据文件。**

所有排序都基于「匹配质量 → 覆盖率 → 长度 → 字典序」。
冷门角色和热门角色一视同仁。

### 这些原则带来的行为

- 为什么有些「泛词」也能勾上 → 因为删了就不可达了
- 为什么同名多义全列出来 → 因为不确定你要哪个
- 为什么精简建议不自动删 → 因为不因不精确就删

## 常见问题

### Q: 打开是空白页？

检查 `lib/library.js` 是否存在。少了就是文件不完整。

### Q: 双击 启动.bat 一闪就没了？

`lib/library.js` 找不到。用命令行运行看报错。

### Q: 「复制」按钮没反应？

Firefox 在 `file://` 下会限制剪贴板。改用 Edge / Chrome，或手动 Ctrl+C。

### Q: 搜角色名搜不到？

先点「🔎 角色/作品/画师库」按钮开启扩展库。默认不加载。

### Q: 能放到 U 盘里用吗？

可以。整个文件夹拷过去双击就能用。

### Q: 会写注册表吗？

不会。纯绿色软件，删掉文件夹就卸载了。

### Q: 为什么有些标签看起来不精确？

见「设计原则」第 ② 条 —— 不因不精确就删。

### Q: 支持 Mac / Linux 吗？

支持。`index.html` 是纯前端页面，任何现代浏览器都能打开。
`启动.bat` 只在 Windows 上有效，其他系统直接双击 `index.html`。
