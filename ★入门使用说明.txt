【一、这是什么】
──────────────────────────────────────────────────────────────────────────────
  一个把「中文口语描述」翻译成「Danbooru 英文标签」并自动组装成提示词的工具。

  · 用中文说你想画什么
  · 工具找出对应的英文标签
  · 自动拼成可以直接拿去出图的正向 / 负向提示词

  ★ 完全离线：不联网、不调 AI、不上传任何东西
  ★ 零安装：双击就能用，不需要装 Python / Node.js
  ★ 纯文件运行：拷到 U 盘、换个目录都能直接用

  ── 数据规模（实测）──
     主词库        51,127 个 Danbooru 标签
     中文映射表    76,431 个键 / 81,561 条映射
     角色库        97,318 条
     作品库        17,152 条
     画师库        31,568 条（只收有中文名的）
     父子关系      13,616 个下位词
     模型预设      20 个
     风格标签      51 个

  ── 目录大小 ──
     首屏必需      约 9.8 MB
     扩展库按需    约 9.0 MB
     合计          18.8 MB


【二、怎么启动】
──────────────────────────────────────────────────────────────────────────────
  方式一（推荐）：双击  启动.bat

      第一次启动会列出你电脑上装了的浏览器，让你选一个。
      选过之后会记住，以后双击就直接打开，不再问。

      ── 菜单里的选项 ──
        [数字]   用列表里对应那个浏览器打开
        [D]      用系统默认浏览器
        [M]      手动输入浏览器路径（便携版浏览器用这个）
        [Q]      退出

      ── 想重新选 ──
        删掉本目录下的「_浏览器设置.txt」即可，
        或者命令行运行：  启动.bat reset

      ── 命令行参数（给会用的玩家）──
        启动.bat default            直接用系统默认浏览器，跳过菜单
        启动.bat reset              清空记住的选择
        启动.bat "D:\浏览器\xx.exe"  临时用指定浏览器

  方式二：直接双击 index.html

      会用系统默认浏览器打开。缺点是没有浏览器选择，且
      某些安全策略严格的浏览器可能限制本地文件读写。

  ── 支持的浏览器 ──
     ✅ Edge / Chrome / Brave / Vivaldi / Opera（Chromium 内核）
     ✅ Firefox / Waterfox / LibreWolf
     ✅ 360极速 / QQ浏览器 / 搜狗高速（国产 Chromium 内核）
     ✅ 任何 Chromium 或 Firefox 内核的浏览器

     ★ 推荐 Chromium 内核（Edge/Chrome/Brave），界面渲染和性能最好。
       Firefox 也能用，但极少数情况下「复制」按钮需要手动 Ctrl+C 兜底。

  ★ 首次打开要加载约 9.8 MB 数据，大概 0.3 秒。
    之后浏览器会缓存，再打开更快。

──────────────────────────────────────────────────────────────────────────────

        道具拘束  场景地点  光影氛围  时间天气  特效修饰

     ② 16 类（勾「16 类视图」开关）

        服装      配饰      姿势动作  互动      身体细节
        道具物件  场景地点  时间天气  镜头构图  光影氛围
        风格其它

     ★ 两种视图只是「换个看法」——
       勾选状态、提示词内容、输出顺序完全不变。
       切过去切回来不会丢任何选择。

  ── 每一行的标记 ──
     ★  = 高置信（默认勾选）
     ◆  = 中置信
     ·  = 低置信

     紫色   = 映射表命中（你说的口语词直接被识别了）
     ⚡     = 高命中自动组装（描述里字面出现的词）
     黄底 + ⚠ + 虚线下划线 = 接地可疑
              意思是"这个词带来了描述里没有的语义"
              例：你说「透明内衣」，它给你「透明椅子」
              鼠标悬停可看具体原因
              ★ 只标记，不删除，不影响召回

  ── 点击操作 ──
     点任意一行  = 切换勾选（点整行都行，不用点小方框）
     右键点一行  = 弹出菜单：
                     ✓ 加入正向
                     ✕ 加入负向（自动切手动模式）
                     ⧉ 复制该词条
                     🔍 搜索这个词

  ── 泛称提示 ──
     点到「泛称词」（如 panties / cum / spread_legs）
     → 自动弹出提示，列出命中率更高的精准替代词，点一下就换

【六、token 预算与精简建议】
──────────────────────────────────────────────────────────────────────────────
  顶部右侧会显示类似：
     核心区 8/9段 · 13/15字段 · 28词 · 约 76 token/估算上限 75 ❌超限

  ── 什么时候会超 ──
     SD1.5 系模型有 75 token 的硬限制（Anything / Counterfeit / MeinaMix 等）
     SDXL 系（Pony / Illustrious / NoobAI / Animagine）宽松得多，只提示「偏长」

  ── 超了怎么办 ──
     超预算时会自动出现「精简建议」区域：

       超出预算约 1 token · 没有可自动判定的精简项
       [查看建议]

     点开能看到：
       · 如果有「明确可删的词」（同义重复、专名噪音等）→ 逐条列出并说明原因
       · 如果没有 → 显示各维度各占多少 token，你自己决定删哪个

     ★★ 工具【绝不自动删除任何词】。
        所有建议都要你自己在界面上取消勾选。
        这是设计原则，不是功能缺失。

  ── 典型用法 ──
     看到「environment 25 tok」占最多
     → 自己判断「城堡大厅」这个场景要不要精简
     → 在卡片上取消勾选对应词
     → 提示词框实时更新


【七、角色 / 作品 / 画师库】
──────────────────────────────────────────────────────────────────────────────
  主词库有身体、动作、服饰、场景这些「属性标签」，
  但【没有】具体角色名、作品名、画师名。这个扩展库补上那一层。

  ── 规模 ──
     角色 97,318 条    例如：初音未来 / 博丽灵梦 / 芙兰朵露·斯卡蕾特
     作品 17,152 条    例如：东方Project / 蔚蓝档案 / 原神 / 赛马娘
     画师 31,568 条    例如：大川bkub / 春山和则 / 荒井启

  ── 怎么用 ──
     1. 点顶部「🔎 角色/作品/画师库」按钮 → 首次点击会加载约 9 MB 数据
     2. 按钮变成「🎭 角色/作品/画师库（已开）」
     3. 正常搜索即可，结果会单独显示在主卡片上方
     4. 点一下就能勾选/取消，勾上后会按位置拼进提示词

  ── 为什么默认不加载 ──
     这 14.6 万条是独立的 9 MB 文件，不影响打开工具的速度。
     不用的时候完全不占内存。再点按钮可以关闭。

  ── 搜索规则 ──
     · 1 个字（如「女」）只做精确匹配，不会刷出上千条
     · 2 个字（如「初音」）做精确 + 前缀匹配
     · 3 个字以上才做包含匹配
     · 同名多义会全部列出（比如「美杜莎」有 10 个）
     · 排序规则：完整名精确 > 主名精确 > 别名 > 前缀 > 包含
     · **绝不按热度排序** —— 冷门角色和热门角色一视同仁

  ── 括号名的处理 ──
     名字带括号的会自动拆出主名：
       「阿尔托莉雅·潘德拉贡 (泳装Ruler) (第一阶段) (Fate)」
       → 搜「阿尔托莉雅」也能命中

  ── 提示词里的位置 ──
     角色名紧跟在「人数」之后，作品名紧跟角色名之后。
     这是 Animagine 官方要求的「角色名后跟作品名」，其他模型也适用。

  ── 数据来源 ──
     ai-prompt-supermarket（MIT 许可，Copyright (c) 2026 BFRKQSB7）
     https://github.com/BFRKQSB7/ai-prompt-supermarket
     上游的 post_count（热度）字段已在生成阶段剔除，运行时不包含。

  ★ 纯英文名的画师（11.7 万条）没有收录 ——
    用户知道 wlop 时直接打英文最准，不占中文索引。


【八、手动改提示词（重要）】
──────────────────────────────────────────────────────────────────────────────
  正向 / 负向两个框【都可以直接编辑】。

  ── 规则 ──
     一改动，右上角显示「✎ 手动编辑中」
     这时自动组装就不再覆盖你的内容

  ── 三个按钮的分工 ──
     ［手动输入］   勾上 = 锁定当前内容
     ［＋ 追加新词］ 把缺失的自动词按原字段位置补回来，你自己加的词留在末尾
     ［↻ 恢复自动］ 放弃手改，回到自动组装

  ── 典型用法 ──
     ① 匹配 → 自动组装好
     ② 在正向框里删掉几个不想要的
     ③ 手动加几个自己的词（比如常用的画师名）
     ④ 点「＋ 追加新词」→ 被删的自动词按原位补回，你的词留在末尾
     ⑤ 复制


【九、搜索技巧】
──────────────────────────────────────────────────────────────────────────────
  ── 中文口语 ──
     「自慰」「扣」「揉下面」「自己玩」 都能识别
     「裙紫」「内库」「屁服」「嘴吧」「眼晴」 打错字也能识别

  ── 中英混合 ──
     「69式」「T字裤」「2穴」「Q版插」 这类含数字/字母的中文词也能识别

  ── 英文标签名 ──
     直接打 panties / long_hair / school_uniform 都行
     打成 pantys / schol_uniform / skrit 也能纠错
     单复数自动识别：golds → gold，underwears → underwear

  ── 归一化 ──
     long hair    = long_hair    （空格）
     long-hair    = long_hair    （连字符）
     ｐａｎｔｉｅｓ  = panties       （全角）
     Long Hair    = long_hair    （大小写）

  ── 多个词一起输 ──
     「校服 蓝发」   两个词分别召回，同时命中两个的排前面
     「blue eyes」  blue_eyes 会被加权

  ── 否定句式 ──
     「不穿内裤」「没有帽子」「不带眼镜」 能正确解析成 no_panties 等

【十一、常见问题】
──────────────────────────────────────────────────────────────────────────────
  Q: 打开是空白 / 提示"数据未加载"
  A: 检查 lib\library.js 是否存在。少了就是文件不完整，重新拷一份。

  Q: 双击 启动.bat 一闪就没了
  A: 说明 lib\library.js 找不到（bat 里有检测，会停住显示提示）。
     如果确实闪退，用命令行运行看报错：cmd → 拖动 bat 进去 → 回车

  Q: 界面很慢 / 卡
  A: ① 换 Chromium 内核浏览器（Edge/Chrome）
     ② 关掉扩展库（再点一次按钮）
     ③ 重启浏览器释放内存

  Q: 「复制」按钮没反应
  A: Firefox 在 file:// 下会限制剪贴板。
     改用 Edge/Chrome，或者手动 Ctrl+A / Ctrl+C。

  Q: 复制出来的词和界面看到的不一样
  A: 检查是否处于「手动编辑中」。手动模式下以你框里的内容为准。

  Q: token 超了但精简建议说"没有可自动判定的精简项"
  A: 这说明描述里每个词都能在原文找到直接依据，
     工具不会因为「不确定」就建议删除。
     这种情况你自己看各维度 token 占用，手动取舍。

  Q: 搜角色名搜不到
  A: 先点「🔎 角色/作品/画师库」按钮开启扩展库。
     默认不加载，所以没开之前搜不到角色。

  Q: 搜「wlop」搜不到画师
  A: 画师库只收了有中文名的 31,568 条。
     纯英文名画师没收录 —— 直接打英文标签本来就最准。

  Q: 想要某个标签但搜不到
  A: 换个说法试试。比如「巨乳」搜不到就试「大胸」「乳巨」。
     还没有的话可以点「词库搜索」直接查词库。

【十三、设计原则】
──────────────────────────────────────────────────────────────────────────────
  这个工具有四条不可违背的红线，理解它们能帮你更好地用它：

  ① 不审核内容
     工具不对任何标签做内容判断。你想画什么就搜什么。

  ② 不因映射不精确就删
     宁可给你一个不够准的标签，也不轻易删掉映射关系。
     只有「语义完全错误」的映射才会被清理，且每条都有正确替代。

  ③ 永远保留可达性
     每个标签至少保留一个能搜到它的入口。
     所以有些「不太常见」的标签也留着。

  ④ 绝不按热度排序
     post_count（Danbooru 热度）从未进入本工具的任何数据文件。
     所有排序都基于「匹配质量 → 覆盖率 → 长度 → 字典序」。
     冷门角色和热门角色一视同仁。

  ★ 这些原则决定了几个你可能会困惑的行为：
     · 为什么有些「泛词」也能勾上 → 因为删了就不可达了
     · 为什么同名多义全列出来 → 因为不确定你要哪个
     · 为什么精简建议不自动删 → 因为不因不精确就删
